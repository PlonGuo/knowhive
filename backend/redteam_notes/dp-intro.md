# 动态规划入门

动态规划（DP）是一种通过把原问题分解为子问题来求解的算法思想。核心是最优子结构和重叠子问题。

常见类型包括线性DP、区间DP、树形DP、数位DP。掌握状态定义和转移方程是关键。
